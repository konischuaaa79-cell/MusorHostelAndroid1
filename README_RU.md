# Вывоз мусора — Android-приложение

## Что умеет
- Список вывозов для нескольких хостелов: название, адрес, дата, время и примечание.
- Индивидуальная дата и время для каждого выезда.
- Календарь по месяцам с отметками дней, в которые запланирован вывоз.
- Напоминания Android за 24 часа и за 2 часа.
- Отметка «Выполнено», список выполненных вывозов и удаление записей.
- Локальное хранение на телефоне, без регистрации и сервера.

## Как собрать APK
1. Установите Android Studio на компьютер.
2. Распакуйте ZIP и откройте папку `MusorHostelAndroid` как проект.
3. Дождитесь синхронизации Gradle. При запросе установите Android SDK 35.
4. Подключите Android-телефон с включённой отладкой по USB или используйте эмулятор.
5. Выберите **Build → Build APK(s)**. APK появится в `app/build/outputs/apk/debug/`.
6. Установите APK на телефон и разрешите уведомления. Если Android попросит разрешение на точные будильники/напоминания, разрешите его в настройках приложения.

## Важно
- Приложение хранит данные только на этом телефоне. Удаление приложения может удалить данные.
- В этой первой версии каждая запись — отдельный вывоз. Повторяющиеся графики и синхронизация между телефонами пока не реализованы.
- Уведомления зависят от разрешений Android и настроек энергосбережения производителя. Проверьте тестовый вывоз с напоминанием на ближайшие часы.
- Для точной сборки требуется Android Studio и SDK; готовый APK в этом архиве не приложен.
